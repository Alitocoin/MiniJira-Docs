## Resumen ejecutivo

El equipo DevForce ejecutó una suite de 5 test sets sobre el sistema MiniJira (Spring Boot + PostgreSQL + React + TypeScript). Por cada test set se creó una branch dedicada en los 3 repos del proyecto (`MiniJira-BE`, `MiniJira-FE`, `MiniJira-Docs`) a partir de `development`. Los 5 tests se ejecutaron en orden secuencial con los specialists asignados a cada área: Carlos Frost (backend), Paula Aguilar (frontend), Juan Mendez (QA) y John Lee (CI/CD). El resultado fue un sistema MiniJira completo con CRUD, tablero Kanban, autenticación JWT, 35 pruebas unitarias (21 verdes en frontend, 24 pendientes de JVM en backend) y pipelines GitHub Actions en BE y FE.

**Sistema:** MiniJira — herramienta de gestión de tareas estilo Jira, con tablero Kanban.
**Stack:** Spring Boot (Java 17) · PostgreSQL · React + TypeScript · Vitest · JUnit 5 · GitHub Actions
